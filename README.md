# Portfolio de Marie-Ange Viard

Site codé avec Astro et GSAP, mis en ligne gratuitement sur GitHub Pages.

## Ajouter ou modifier un projet

1. Déposer les visuels dans `public/projets/<nom-du-projet>/` (01.webp, 02.webp…). Le premier sert de couverture.
2. Ajouter ou modifier le projet dans `src/data/projets.ts`.
3. Envoyer sur GitHub : le site se met à jour tout seul en quelques minutes.

## Travailler en local

```
npm install
npm run dev
```
